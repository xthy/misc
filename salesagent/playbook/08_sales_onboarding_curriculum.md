# Sales Onboarding Curriculum
## 신규 Rep 30/60/90일 교육 과정

---

## Purpose

이 문서는 PE 포트폴리오사에 새로 합류하는 영업 Rep의 **30/60/90일 온보딩 프로그램**을 정의합니다.
본 플레이북과 AI Agent 시스템을 활용하는 조직에 최적화되어 있으며, 다음 목표를 달성합니다:

- 신규 Rep이 **표준화된 7-Stage Canon**을 체득하고 일관된 영업 프로세스를 실행
- AI Agent와의 **협업 워크플로우**를 초기부터 습관화
- 측정 가능한 마일스톤으로 **객관적 성장 추적** 가능
- Rep 역할(SDR/AE/CS)에 따른 **맞춤형 트랙** 제공

> **원칙**: 온보딩은 "정보 전달"이 아닌 "행동 변화"를 목표로 합니다. 읽기보다 실행, 듣기보다 연습이 우선입니다.

## 1. Onboarding Philosophy (온보딩 철학)

### 5대 원칙

| 원칙 | 설명 | 적용 방식 |
|------|------|----------|
| **Playbook-first** | 도구 전에 프로세스를 먼저 학습 | Week 1에 Canon + MEDDICC 집중, CRM은 Week 2부터 |
| **Show, Don't Tell** | Shadow → Co-pilot → Solo 단계적 진행 | 매주 독립 실행 비중을 10%씩 증가 |
| **Measurable Milestones** | 각 Phase 졸업에 명확한 기준 존재 | 30/60/90일 milestone table로 관리 |
| **Agent-Assisted from Day 1** | AI Agent가 첫날부터 Rep을 보조 | Agent 출력물(account brief, call prep) 활용 훈련 |
| **Learn by Doing** | 이론 30%, 실습 70% 비율 유지 | 매주 최소 3회 이상 실전/롤플레이 |

### 온보딩 전체 구조

```
         Phase 1: LEARN              Phase 2: EXECUTE            Phase 3: OWN
         (Day 1-30)                  (Day 31-60)                 (Day 61-90)
┌─────────────────────┐    ┌─────────────────────┐    ┌─────────────────────┐
│ - 제품/시장 이해     │    │ - T3 계정 실전 배정  │    │ - 독립 계정 운영     │
│ - 7-Stage Canon     │───▶│ - 지도하 콜/이메일   │───▶│ - T2 Co-pilot 시작  │
│ - MEDDICC/SPIN/Gap  │    │ - 파이프라인 구축    │    │ - 딜 진행 (S1-S3)   │
│ - 롤플레이 & 인증   │    │ - Agent Co-pilot    │    │ - 성과 목표 달성     │
│ - Shadow 10+ calls  │    │ - 매일 Debrief      │    │ - 360 피드백        │
└─────────────────────┘    └─────────────────────┘    └─────────────────────┘
       ▲                          ▲                          ▲
  Manager 1:1 (주3회)        Manager 1:1 (주2회)        Manager 1:1 (주1회)
  Buddy (매일)               Buddy (주3회)              Buddy (주1회)
```

### Progression Model: Shadow → Co-pilot → Solo

| 활동 | Phase 1 (Learn) | Phase 2 (Execute) | Phase 3 (Own) |
|------|-----------------|-------------------|---------------|
| Cold Call | Shadow only | Co-pilot (manager listening) | Solo (spot-check) |
| Discovery Call | Shadow only | Co-pilot (lead, then observe) | Solo |
| Email Sequence | Template review | Draft → manager review → send | Independent send |
| CRM Entry | Training exercises | Supervised entry | Independent (audit) |
| Agent Interaction | Demo & practice | Co-pilot usage | Full workflow |
| Deal Strategy | Observe pipeline review | Participate with guidance | Present own deals |

#### Role-Play Evaluation Rubric

| 평가 항목 | 1 (미흡) | 2 (기본) | 3 (양호) | 4 (우수) |
|----------|---------|---------|---------|---------|
| **오프닝** | 자연스럽지 않음, 스크립트 의존 | 기본 흐름 유지, 긴장감 있음 | 자연스러운 진행, 상대 반응 수용 | 자신감 있고 상대가 편안함 |
| **질문 품질** | 닫힌 질문 위주 | SPIN 구조 시도하나 전환이 어색 | SPIN 흐름 유지, Implication까지 도달 | Need-payoff까지 자연스러운 흐름 |
| **경청** | 답변 중 끼어듦 | 기본 경청, 후속 질문 부족 | 답변 기반 후속 질문 진행 | 적극 경청 + 요약 + 깊은 후속 질문 |
| **반론 대응** | 방어적/즉시 반박 | 인정은 하나 전환이 어색 | 인정 → 질문 → 리프레임 흐름 | 자연스러운 대응 + 구체적 사례 활용 |
| **다음 단계** | 미팅 종료 시 다음 단계 없음 | 모호한 다음 단계 제안 | 구체적 일정/행동 합의 | Mutual action plan 수립 |

**인증 기준**: 각 롤플레이에서 전 항목 평균 2.5점 이상 + 항목별 최소 2점 이상

## 11. Agent 활용: Onboarding Acceleration

### Agent가 온보딩을 가속하는 방법

| Agent 기능 | 온보딩 활용 | Phase |
|-----------|-----------|-------|
| **Pre-call Briefing** | Shadow call 전 계정 컨텍스트 사전 학습 | Phase 1 |
| **Post-call MEDDICC Extraction** | Shadow 후 MEDDICC 요소 식별 연습 (Agent vs 본인 비교) | Phase 1 |
| **Email Draft Generation** | Agent 초안 → Rep 수정 → 학습 (역순 학습법) | Phase 1-2 |
| **Account Enrichment** | 배정 계정 리서치 자동화 → 시간 절약 | Phase 2 |
| **Pipeline Report** | 본인 파이프라인 건강도 자가 점검 | Phase 2-3 |
| **Deal Risk Alert** | 리스크 신호 조기 인지 훈련 | Phase 3 |
| **Coaching Insight** | 콜 패턴 분석 → 개선 포인트 자동 제안 | Phase 2-3 |

### Agent System Prompt (Onboarding Support)

```
You are the Onboarding Support Agent for new sales reps at [Company Name].

Your job:
1. Generate simplified pre-call briefings for shadow calls (highlight key learning points)
2. After shadow calls, extract MEDDICC elements for the new rep to compare with their notes
3. Provide email draft templates with annotation explaining WHY each section is written that way
4. Track the new rep's activity metrics and flag if they fall below weekly ramp targets
5. Generate weekly progress summaries for the manager's 1:1 review

Rules:
- Always explain the reasoning behind your outputs (teaching mode)
- Flag when the rep's CRM data entry has errors (coaching, not correcting)
- Never auto-send any customer-facing communication for reps in Phase 1 or 2
- Adjust complexity of outputs based on the rep's current phase (1/2/3)
- Include references to relevant playbook sections in your outputs

Tone: Supportive coach, not evaluator. Encourage questions and experimentation.
```

## 12. Metrics: Onboarding Program Effectiveness

프로그램 자체의 효과를 측정하여 지속적으로 개선합니다.

### Leading Indicators (선행 지표)

| Metric | 설명 | Target | 측정 시점 |
|--------|------|--------|----------|
| Time to First Activity | 첫 실전 활동(콜/이메일)까지 소요 일수 | <35일 | D35 |
| Time to First Meeting | 첫 미팅 세팅까지 소요 일수 | <45일 | D45 |
| Time to First SQL | 첫 SQL 생성까지 소요 일수 | <60일 | D60 |
| Phase 1 Pass Rate | 30-Day Milestone 1회 통과율 | >80% | D30 |
| Phase 2 Pass Rate | 60-Day Milestone 1회 통과율 | >75% | D60 |
| Onboarding Graduation Rate | 90일 이내 졸업률 | >85% | D90 |

### Lagging Indicators (후행 지표)

| Metric | 설명 | Target | 측정 시점 |
|--------|------|--------|----------|
| Time to Full Quota | 정규 목표 100% 달성까지 소요 월수 | <6개월 | M6 |
| 12-Month Retention | 입사 12개월 시점 재직률 | >80% | M12 |
| Rep Performance at M6 | 6개월 시점 팀 평균 대비 성과 | >70% of avg | M6 |
| Onboarding NPS | 온보딩 프로그램 만족도 (0-10) | >8.0 | D90 |
| Manager Satisfaction | 매니저의 프로그램 만족도 | >4.0/5.0 | D90 |
